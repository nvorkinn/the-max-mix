# Security policy

## Supported versions

Only the latest [release](https://github.com/nvorkinn/the-max-mix/releases/latest) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
[Security > Report a vulnerability](https://github.com/nvorkinn/the-max-mix/security/advisories/new).

Useful details: what you found, the version or commit, steps to reproduce, and the impact (for example exposure of
Spotify tokens or the contents of `server/.env`). You can expect an initial reply within a few days.
