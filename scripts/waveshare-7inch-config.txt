# Waveshare 7-inch HDMI/USB touchscreen, 1024x600
#
# Current Raspberry Pi OS uses the KMS driver and labwc/Wayland.
# First use the desktop display settings to select 1024x600 and orientation.
# HDMI EDID normally supplies the supported modes. Connect USB for touch input.
#
# Check /boot/firmware/config.txt for the existing KMS overlay:
# dtoverlay=vc4-kms-v3d
# Do not append a second copy if the OS already enables it.
#
# If the screen does not advertise a usable mode, follow the instructions for
# your exact Waveshare model and Raspberry Pi OS version. Back up boot files
# before forcing a connector/mode. This file is guidance, not an installable
# config.txt block.
#
# Legacy hdmi_group/hdmi_mode/hdmi_cvt and display_rotate settings are not a
# portable way to configure displays with modern KMS. Do not apply the old
# Bullseye/X11 timing block blindly.
